# 📘 Guide d'Utilisation - Espace Administrateur

Bienvenue dans votre guide d'utilisation ! Ce document a été conçu spécialement pour vous aider à gérer votre site internet en toute simplicité. Pas besoin d'être un expert en informatique, il vous suffit de suivre ces étapes pas à pas.

---

## 1️⃣ Comment se connecter à votre espace ?

Pour modifier votre site ou voir vos commandes, vous devez vous connecter à votre "Espace Administrateur" (les coulisses de votre site).

1. Ouvrez votre navigateur internet habituel (Chrome, Safari, Edge, etc.).
2. Allez sur la page de connexion de votre site (l'adresse vous sera fournie, elle se termine généralement par `/admin/login`).
3. Vous allez voir une page avec des cases à remplir :
   - Dans la case **Email**, tapez votre adresse e-mail.
   - Dans la case **Mot de passe**, tapez votre mot de passe secret.
4. Cliquez sur le bouton **Se connecter**.

🎉 *Bravo ! Vous êtes maintenant dans votre espace privé.*

---

## 2️⃣ Découvrir le menu de navigation

Une fois connecté, regardez sur le côté de votre écran. Vous verrez un menu avec plusieurs rubriques. Voici à quoi elles servent :

- **Tableau de bord** : C'est la page d'accueil de votre espace, pour voir un résumé rapide de votre activité.
- **Boutique / Produits** : C'est ici que vous ajoutez ou modifiez les plantes ou articles que vous proposez.
- **Commandes** : Pour voir les achats réalisés par vos clients.
- **Galerie (Portfolio)** : Pour montrer les belles photos de vos réalisations (vos chantiers, vos plus beaux jardins).
- **Catégories** : Pour ranger vos produits ou vos photos dans des "dossiers" (par exemple : "Fleurs", "Arbres fruitiers", "Entretien").

---

## 3️⃣ Comment ajouter une photo dans votre Galerie ?

C'est très important de montrer votre savoir-faire. Voici comment ajouter une nouvelle réalisation :

1. Dans le menu, cliquez sur **Galerie** (ou Portfolio).
2. Cherchez et cliquez sur le bouton **Ajouter** (souvent représenté par un signe **+**).
3. Remplissez les informations très simplement :
   - **Titre** : Donnez un nom à votre travail (exemple : "Création d'un jardin zen").
   - **Description** : Expliquez en quelques mots ce que vous avez fait.
   - **Image / Photo** : Cliquez sur le bouton pour choisir la photo directement depuis votre ordinateur.
   - **Catégorie** : Cochez la case qui correspond le mieux.
4. Quand vous avez terminé, n'oubliez pas de cliquer sur le bouton **Enregistrer** (ou Sauvegarder).

*Et voilà, votre nouvelle photo est visible par tous vos visiteurs !*

---

## 4️⃣ Comment ajouter un nouveau Produit dans la boutique ?

1. Dans le menu, cliquez sur **Produits**.
2. Cliquez sur le bouton **Ajouter un produit**.
3. Complétez les cases demandées :
   - Le **nom** de la plante ou du produit.
   - Le **prix**.
   - Une petite **description** pour donner envie de l'acheter.
   - Une jolie **photo**.
4. Cliquez sur **Enregistrer**.

---

## 5️⃣ Comment voir vos Commandes ?

Quand un client vous achète quelque chose sur le site, voici comment le voir :

1. Dans le menu, cliquez sur **Commandes**.
2. Vous verrez la liste de toutes les personnes qui ont passé commande.
3. Cliquez sur une commande pour l'ouvrir et voir les détails : qui est le client, où habite-t-il, et qu'a-t-il commandé.

---

## 💡 Quelques petits conseils pour finir :

- **Prenez votre temps** : Lisez bien ce qui est écrit sur les boutons avant de cliquer. Il n'y a pas d'urgence.
- **Pas de panique !** : Si vous vous trompez (une faute de frappe, une mauvaise photo), vous pourrez toujours revenir en arrière ou "Modifier" ce que vous avez fait.
- **La taille des photos** : Essayez de mettre des photos de bonne qualité, mais si elles mettent du temps à charger depuis votre ordinateur, c'est normal, laissez l'ordinateur travailler quelques secondes.

**Bonne utilisation de votre nouveau site internet !**
