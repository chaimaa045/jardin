# 📘 Guide Pratique : Gérez votre site facilement

Bonjour ! Ce petit guide a été pensé spécialement pour vous. Gérer votre site internet ne demande **aucune compétence en informatique**. Tout a été pensé pour être aussi simple qu'envoyer un message sur votre téléphone.

Suivez le guide, étape par étape !

---

## 1️⃣ Comment se connecter à votre espace d'administration ?

L'espace d'administration, c'est l'arrière-boutique de votre site. C'est là que vous pouvez modifier vos photos, voir vos commandes ou changer vos informations. 

Voici le secret pour y accéder facilement :
1. Allez sur votre site internet depuis votre téléphone ou votre ordinateur.
2. Descendez **tout en bas de la page** (là où il y a les informations de contact).
3. Regardez tout en bas à droite de l'écran, juste à côté de l'année et du texte "Tous droits réservés". Vous verrez **un tout petit point (`•`)**.
4. **Cliquez sur ce petit point**. C'est une porte secrète vers votre espace privé !
5. Une fois sur la page de connexion, tapez votre e-mail et votre mot de passe, puis validez.

---

## 📱 *NOUVEAU* : Installez votre espace comme une application sur votre téléphone !

Pour ne pas avoir à chercher le petit point à chaque fois, vous pouvez **installer l'espace d'administration directement sur l'écran d'accueil de votre téléphone** (comme l'application WhatsApp ou Météo) !

**Si vous avez un iPhone :**
1. Allez sur la page de connexion (via le petit point).
2. En bas de votre écran, cliquez sur l'icône de partage (le petit carré avec une flèche qui pointe vers le haut).
3. Glissez vers le bas et appuyez sur **"Sur l'écran d'accueil"**.
4. Validez en cliquant sur **"Ajouter"**. 
Un nouveau logo apparaîtra avec vos autres applications ! Vous n'aurez plus qu'à cliquer dessus la prochaine fois.

**Si vous avez un Android (Samsung, Xiaomi...) :**
1. Allez sur la page de connexion.
2. Votre téléphone va souvent vous proposer un bouton "Installer l'application" en bas de l'écran. 
3. S'il ne le propose pas, cliquez sur les trois petits points en haut à droite de l'écran, puis sur **"Ajouter à l'écran d'accueil"**.

---

## 2️⃣ Découvrir le menu de navigation

Une fois connecté, vous avez un menu très simple avec plusieurs rubriques. 

- **Tableau de bord** : C'est le résumé. Vous y voyez d'un coup d'œil quelques informations utiles (comme le nombre de commandes).
- **Boutique / Produits** : Pour gérer les plantes, pots, ou matériels que vous vendez.
- **Commandes** : Pour voir les clients qui vous ont acheté quelque chose.
- **Galerie (Portfolio)** : Pour mettre les plus belles photos de vos jardins et chantiers.
- **Catégories** : Pour ranger vos photos et vos produits dans des "dossiers" (ex: "Fleurs", "Entretien").
- **Paramètres** : Pour changer votre numéro de téléphone, votre description ou votre adresse.

---

## 3️⃣ La Boutique : Comprendre les Catégories et le Stock

Si vous souhaitez vendre des plantes ou du matériel sur votre site, voici comment cela fonctionne. L'idée est simple : on commence par créer des "rayons" (les catégories), puis on y place des "articles" (les produits).

### Étape 1 : Les Catégories (Créer des "rayons")
Avant d'ajouter un produit, il faut lui créer un "rayon" dans votre boutique.
1. Dans le menu, cliquez sur **Catégories**.
2. Cliquez sur le bouton **Nouvelle Catégorie**.
3. Donnez-lui un nom clair (par exemple : *Arbres Fruitiers*, *Plantes d'intérieur*, *Engrais*).
4. Cliquez sur **Enregistrer**.

### Étape 2 : Ajouter un Produit et gérer le Stock
Une fois le "rayon" (la catégorie) créé, vous pouvez y mettre un produit.
1. Cliquez sur **Boutique / Produits** dans le menu.
2. Cliquez sur **Nouveau Produit** (le bouton avec un **+**).
3. Remplissez simplement les informations :
   - Le **Nom** du produit (ex: "Olivier centenaire").
   - Le **Prix** de vente.
   - La **Catégorie** (Choisissez "Arbres Fruitiers" que vous venez de créer).
   - Le **Stock** : C'est le nombre de plantes que vous avez actuellement à vendre dans votre vraie boutique (ex: 5). **C'est très important :** si le stock arrive à zéro, le produit affichera "Rupture de stock" sur le site. Les clients ne pourront plus l'acheter pour rien.
   - L'**Image** : Ajoutez une belle photo depuis votre téléphone.
4. **Enregistrez**. Votre produit est en ligne ! 
*Note magique : À chaque fois qu'un client achètera ce produit, le stock diminuera tout seul sur le site. Vous n'avez rien à calculer.*

---

## 4️⃣ Gérer vos Commandes clients

Lorsqu'un client passe une commande sur votre site, tout se retrouve ici :

1. Cliquez sur **Commandes** dans le menu.
2. Vous verrez la liste de tous vos clients. Les nouvelles commandes apparaissent avec un statut bien visible (ex: "Nouvelle").
3. Cliquez sur le bouton "Détails" (ou l'icône de l'œil) à côté d'une commande pour l'ouvrir.
4. Vous y verrez le nom du client, son adresse de livraison, son numéro de téléphone pour l'appeler, et la liste des plantes qu'il veut acheter.
5. Une fois que vous avez préparé sa commande ou que vous l'avez livré, vous pouvez changer le **Statut** de la commande (en la passant de "En attente" à "Livrée") pour vous organiser et ne pas la confondre avec les nouvelles commandes.

---

## 5️⃣ Comment ajouter une magnifique photo dans votre Galerie ?

Rien de tel que de belles images de vos chantiers pour attirer de nouveaux clients. Voici comment faire :

1. Dans le menu, cliquez sur **Galerie**.
2. Cliquez sur le gros bouton **"Nouveau projet"**.
3. Remplissez les informations très simplement :
   - **Titre** : Le nom de votre réalisation (ex: "Création d'un jardin avec gazon").
   - **Description** : Expliquez en deux mots ce que vous avez fait.
   - **L'Image Principale** : Cliquez sur la grande case pour aller chercher la belle photo depuis votre appareil.
   - **Images supplémentaires** : Vous pouvez même ajouter plusieurs autres photos de ce même jardin d'un coup dans la case "Galerie" !
   - **Catégorie** : Choisissez le bon dossier (ex: Entretien). *(Si le dossier n'existe pas, vous pouvez le créer de la même manière que pour la boutique !)*
4. Enfin, cliquez sur **Enregistrer**.

*Et voilà ! Vos futurs clients peuvent maintenant admirer votre travail sur le site.*

---

## 💡 Trois petits conseils pour finir :

- **Pas de panique !** : Vous ne pouvez pas "casser" le site. Si vous vous trompez (une faute de frappe, une mauvaise photo), vous pourrez toujours revenir en arrière, modifier ce que vous avez fait, ou le supprimer.
- **Le poids des photos** : Les photos récentes prises par téléphone sont très belles mais parfois très "lourdes". Quand vous enregistrez un produit ou une réalisation, laissez l'ordinateur charger la photo pendant quelques secondes sans rien toucher jusqu'à ce qu'il vous dise que c'est bon.
- **Prenez votre temps** : Lisez ce qui est écrit à l'écran. Tout est pensé pour vous guider en douceur.

**Bonne utilisation de votre nouveau site internet !**
